# 体验需求实施计划

顺序分三档。细节和已定边界见 [EXPERIENCE_REQUIREMENTS.md](EXPERIENCE_REQUIREMENTS.md)。同一档里靠前的先做。当前先做优先解决，做完再回到三档里还没完成的条目。

## 优先解决

1. **发送队列。** 回复工人仍是一个，后一条等待。要发送的消息一定先进入单独的发送任务队列，有非空正文，入队后不能被后一条覆盖或丢掉。队列满了也等到入队，不能只记跳过。接话里「没必要回」的优先级调低。详见 [SEND_QUEUE_REQUIREMENTS.md](SEND_QUEUE_REQUIREMENTS.md)。
2. **识图 API。** 接口已实现。有图的回合要等识图有结果再写入发送队列，这一步还没做。详见 [VISION_QUEUE.md](VISION_QUEUE.md)。
3. **登录。** 单独的登录进程启动或复用 NapCat，不占用回复工人。没有 OneBot 配置就新建本机 `ws://127.0.0.1:3001`、数组消息段、自身消息上报和随机令牌；已有配置只读，不覆盖，不另造令牌。人扫码，并只填模型 API。扫码成功后重读当前账号真正生效的配置，写入地址、OneBot 令牌和 QQ 号。读不到就停下说明，不编造。填入 API 后可以核对连接，回复保持暂停。不打印令牌，不发消息。

## 一、影响使用

1. **消息不被吞。** 见优先解决的发送队列。还没实现：仍会把还没开始的主动接话换成最新一条，队列满了也会丢掉。
2. **接话。** 已实现真实 @ 能接上就回，没读到画面时按文字接。沉默改入发送队列仍见优先解决。自适应接话见实验功能。
3. **识图。** 接口已实现，智谱识图已放弃。等识图结果再入队还没做，见优先解决。
4. **人设。** 已实现。大小姐的态度不扩散到主人身上。本轮只留发言人和被点到的人。
5. **记忆方向。** 已实现。私聊可读该用户相关的群记忆。群聊不可读私聊。
6. **来源过滤。** 已实现。每个群可填不接话的 QQ，计数前生效，避免两个机器人对吵。
7. **戳一戳。** 已实现。单独处理，不占用普通回复的工人。
8. **按人接话。** 已实现。不接、只在 @ 时接、上限、频率、更容易接话。与来源过滤共用一份名单。

## 二、优化体验

9. **登录。** 见优先解决。登录进程负责 NapCat、扫码后的配置和 QQ 号。人只扫码并填写模型 API。
10. **日志和思考。** 已实现。Debug 才输出详细日志。思考过程输出是单独开关，默认关，只写到面板。思考等级为关、低、高、最大。分层提示词可在面板查看。整段提示词可编辑仍是需求。
11. **花费。** 已实现显示 token，并在填了单价后显示金额。单日、单周金额上限到了就不再调用模型。
12. **记忆。** 可查看。整理只出候选，删除要用户确认，也可自己勾选。非超级记忆不整库放内存。
13. **热重载。** 改配置不打断已经开始的回复。
14. **多 API 与中转站。** QQ 回复现在固定请求 `https://api.deepseek.com`。要能改成用户填写的 OpenAI 兼容中转地址，密钥单独填写，不写进仓库，默认仍是官方。中转站的密钥不能当作官方密钥。已试过 `https://sub.ciallo.cafe/v1`：鉴权通过，但模型名必须用中转站自己的名单，`deepseek-flash` 不在其中；`deepseek-v4.1-flash` 能回复，也能看图。看图时即使要求关闭思考，中转站仍返回思考过程，输出上限太小会把正文截断。普通对话和识图的请求格式见 [RELAY.md](RELAY.md)。每个私聊、每个群可选。失败时换备用，不发半截回复。社交模块已经能填地址，QQ 回复还没有。
15. **本机时间。** 已实现。每次回复前都透传本地时间、日期、星期和时区偏移，不写记忆，不带城市。不必每句主动报时。

## 三、额外功能

默认关闭。前两档稳定之前不做。下面两项可以单独打开。

16. **自适应接话。** 可选。每条群消息都判断要不要接，但开口保守，自动接话而不话痨。详见需求文档。
17. **内容审查。** 可选。输入防提示词注入，输出审查回复正文。两个方向各自开关，不要求一起开。详见需求文档。
18. 表情包、彩蛋里的市区、笨蛋行为。
19. 联网，以及需要时效信息时的主动联网。
20. 向量检索接口。
21. 超级压缩。均衡和极速在接近模型上下文上限时，单独整理成核心目标和高密度摘要。详见需求文档。
22. MAX · 绝对专注记忆。和现有超级记忆分开：每轮新 session，传入可配置条数的聊天上下文，以及另一个 AI 找来的记忆。详见需求文档。
23. 提示词自动 RSI。改写对照面板第一版，只收紧语气。详见需求文档。
